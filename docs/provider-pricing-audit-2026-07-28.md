# 橙月画布 API 成本审计

审计日期：2026-07-28

## 口径

- MetaJing 原始模型价格来源：<https://metajing.cn/api/pricing>、<https://metajing.cn/api/video/models>。
- MetaJing 页面公示 `gpt-image-2` 为 `$0.0600/次`。本账号实际采购口径为 `$1 MetaJing 额度 = ¥1`，因此 Image 2 实际成本是 `¥0.06/次`。
- MetaJing 公共状态接口展示的在线人民币充值汇率可能为 `7.3`；它不代表本账号当前的实际额度采购成本。上线前应继续用充值账单和额度到账记录对账。
- MiniMax Global 原始价格来源：<https://platform.minimax.io/docs/guides/pricing-paygo>。当前接口地址是 `https://api.minimax.io`，继续按真实美元汇率 `1 USD = 7.30 CNY` 核算。
- 橙月画布：`1 积分 = 1 CNY`。
- 当前平台售价：人民币上游成本乘 `1.65`，再向上取整到 `0.001` 积分。
- 表内人民币成本不含支付通道手续费、税费、退款损耗、失败补偿和服务器成本。

## 核心结论

此前系统使用单一 `PLATFORM_USD_TO_CNY=7.3`，错误地将 MetaJing 美元额度也按真实美元换算，导致 Image 2 和 Seedance 成本都被高估了 `7.3` 倍。现已拆成供应商独立配置：

```text
PLATFORM_METAJING_USD_TO_CNY=1.0
PLATFORM_MINIMAX_USD_TO_CNY=7.3
```

因此 Image 2 的上游成本是 `¥0.06/张`，按当前 `1.65x` 规则及 `0.001` 积分计费精度，平台售价为 `0.099 积分/张`。

基础毛利率公式为：

```text
毛利率 = (售价 - 成本) / 售价
```

以 Seedance 720P Pro 15 秒为定价锚点：上游成本 `¥6`、平台售价 `9.9 积分`，反推零售倍数为 `1.65x`，对应毛利率 `39.39%`；千分之一积分的向上取整只会造成很小偏差。

Agent 已按上述零售价接入平台钱包：调用前冻结 `2` 积分，成功后区分普通输入、缓存输入与输出 Token，按真实用量向上取整到 `0.001` 积分结算，失败或中断自动释放冻结积分。每轮保存价格快照，环境变量调整只影响新发起的轮次。
