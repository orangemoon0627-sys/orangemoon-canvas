# 待测试

- 团队空间：注册用户创建团队后，可按邮箱直接添加已注册成员或生成一次性邀请链接；成员切换空间后只能看到该空间的画布、资产、媒体和 Agent 对话。OWNER/ADMIN/EDITOR/VIEWER 权限应分别生效，VIEWER 不能写入或发起付费生成；团队生成与 Agent 使用应从发起人的个人积分扣除，不应扣团队余额。两名成员打开同一画布时，远端更新应在约 5 秒内进入无本地待保存修改的页面，旧标签页写入不能覆盖较新的云端版本。
- 导演台：从工具栏新建“导演台”节点并双击打开；确认舞台始终是 WebGL 三维空间，不再出现二维图层模式。验证八种人物体型、动作预设、属性区逐关节 XYZ 调整、舞台直接点选关节和旋转 Gizmo、对象和场景整体移动/旋转/缩放、导演/机位视角、摄影机实体、注视线、实时机位预览、FOV 与主舞台视锥联动、平面布景板和 720° 全景球；继续验证添加对象/机位/镜头、场景树选择、W/E/R、复制、显隐、锁定、删除、环境、GLB 模型、时间轴播放和关键帧插值。点击截图应输出图片节点，点击 Seedance 图标应输出包含人物姿态、场景整体变换、机位与 FOV 的运镜文本节点；关闭后重新打开，全部状态应随云端画布恢复。移动端使用左右抽屉，优先使用单文件 GLB，GLTF 外部纹理需要人工确认。
- Agent 导演台与空间上下文：在团队画布 Agent 中要求创建导演台，应调用 `canvas_create_director_scene`；修改现有场景应调用 `canvas_update_director_scene` 原地保留节点 ID、位置和连线；导出提示词应调用 `canvas_export_director_prompt`。切换团队空间或重新进入画布后，SSE、线程历史、工具目标和计费请求不能串到其他空间。
- Agent 真实素材导演台：在当前画布已有图片/视频节点时，让 Agent 用 `sourceNodeId` 创建背景、人物、道具和前景，确认场景对象会带回真实媒体地址、存储键、尺寸、`cover/contain` 规则与正确图层顺序；确认素材节点会自动连到导演台，重复更新不会产生重复连线；传入不存在、非媒体或无媒体地址的节点时，应在执行前给出明确错误且不创建导演台。
- 数据库迁移：生产执行新 Prisma migration 前备份 PostgreSQL 与媒体卷，并在临时数据库核对历史用户个人空间、成员、画布、资产、媒体、AgentThread 和 AgentTurn 的回填数量；确认外键、唯一约束和回滚/恢复方案后再发布。
- 云端媒体保存状态：打开含云端图片、视频或对话附件的旧画布后，媒体应正常显示，顶部应从“保存中”变为“已保存”，不得因浏览器临时预览地址误报“保存失败”；刷新页面后节点、连线、对话和媒体仍应完整恢复。未上传且没有媒体存储键的本地文件仍必须阻止云端覆盖并提示恢复。
- 视频播放与修复：新完成的 Seedance 视频应保存为 `/platform-api/canvas-media/...` 同源媒体并可立即播放、暂停和拖动进度；网络面板应看到 Range 请求返回 `206` 和正确的 `Content-Range`。旧 MetaJing 临时外链失效时，视频节点应显示可理解的错误与“修复媒体”按钮；源链接仍有效时修复后应改为平台媒体并在刷新后继续播放。
- 创作 Skill：右侧 Agent 空状态应显示 Image 2 视觉开发、Seedance 镜头导演、视频提示词反推和完整短片工作流四个入口；点击后只填入对应完整请求，Agent 应按需调用 `creative_skill_get`，不得一次加载全部规则。视频反推 CLI 默认按标准档覆盖时间线且不请求模型，显式 `--analyze` 时应最多发送 8 帧并输出结构化 JSON 和可读提示词，明确结果不是原始提示词；用户只需粗略概要时可主动选择 5 帧快速档。当前会话出现包含视频概要、视觉指纹和 Seedance 的完整反推结果后，输入区应显示“一键改写最近反推稿”图标；点击应直接复用既有结果，给出三档原创方向并展开推荐方案，不得重新下载、抽帧或逐镜换皮。
- 账户画布云同步：首次登录应自动归户当前域名 IndexedDB 中的旧画布；退出后重新登录、换浏览器或换设备，应恢复项目列表、节点/连线、提示词、视口、内置助手上下文和右侧 Terra 对话。图片/视频/音频应从账户媒体卷懒加载；删除画布后旧标签页不得把它复活。旧 `sslip.io` 域名中的项目需在该域名登录一次后迁入正式域名。
- Agent 重连：收起再打开右侧 Agent、从首页进入画布或刷新项目页时，输入区必须等待当前网页连接完成后才可发送，不得再出现“当前网页未连接”；重新握手后应恢复该画布历史和运行状态。

- 香港内测部署：受限 Compose、独立网络/卷、生成并发保护和 PostgreSQL 每日备份已完成；需要在正式域名 DNS 生效后确认 `canvas.orangemoon.tech` HTTPS，并用轮换后的 MetaJing Key 完成真实 Image 2 / Seedance 生成。
- 真实供应商生成：使用只存在于服务端的 MetaJing 密钥验证 Image 2 文生图和 2-4 张参考图融合；验证五个真实视频 API 的提交与最终轮询。431 两款只应显示 480P/720P、5/10/14 秒、最多 4 图/3 视频/1 音频；Seedance 2.0 两款按各自 5/10/15 秒和 9 图/3 视频/3 音频限制；`qy-seedance-2.5` 应显示 480P/720P、4-29 秒、30 图/10 视频/10 音频，并验证全能参考、首帧、首尾帧及带参考视频 1.6 倍预授权。上传超过 15MB 的 PNG 后应保留在参考区，并在生成前自动优化而不是直接失败；失败任务不得实扣积分。使用 MiniMax 服务端密钥验证 HD/Turbo MP3。
- 账户与计费：普通账户只显示平台售价，管理员同时显示上游成本和实际毛利率；充值固定 `1 元 = 1 积分`，模型售价按成本 `1.65x` 及 `0.001` 积分精度结算，目标毛利率约 `39.39%`，账户资产、使用记录和积分流水只能看到本人数据；手机窄屏可点击标签栏更多按钮切换被折叠的栏目。
- Terra Agent 计费：发送前应冻结 `2` 积分，余额不足时不得调用上游；成功后按普通输入、缓存输入和输出的真实 Token 结算，多余冻结积分立即返还，对话回复显示本轮 Token 与积分，账户使用记录和积分流水同步出现；失败、中断及幂等重试不得重复扣费。

- 提示词中心布局：页面标题及提示词总数应居中；连续输入搜索文字时应在停止输入约 300ms 后再查询；桌面端分类与标签应在左侧独立滚动，右侧搜索框下直接展示提示词卡片；标签数量较多时不能继续向下挤压提示词，窄屏下应恢复上下排列且内容不溢出；不再显示「我的提示词」Tab，收藏提示词应直接加入我的资产。
- 提示词来源：6 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、53、76、126、129；提示词仍按 6 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。
- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。
- 画布提示词库：不应再显示「我的提示词」分组；不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成配置节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史或日志切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示向下箭头且新消息不强制打断阅读，点击箭头后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧以主题浅底气泡显示，AI 回复应在左侧保留 Agent 图标并使用开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。
